Today I spent the day practicing JavaScript by making a small Task Manager app. I learned how to use arrays, objects, functions, DOM, conditionals, and events. I used arrays to store tasks and worked with them using .push(), .filter(), .map(), and .length. Each task is an object with a name and a status, so I learned how to change object properties and use the spread operator. I made functions to add tasks, show tasks, mark tasks complete, delete tasks, and update counters. I also used the DOM to create and show HTML elements on the page and get input from the user. I added event listeners to make buttons work, and used conditionals to filter tasks into all, completed, or pending.
