##  tittle 
Task Manager


### description


This is a simple Task Manager web application built using JavaScript, HTML, and CSS. The app allows users to add, view, update, and delete tasks. It helps users keep track of their tasks by organizing them into all, completed, and pending categories.

The main purpose of this project is to practice and demonstrate JavaScript fundamentals such as arrays, objects, functions, DOM manipulation, conditionals, and event handling while building a practical, interactive application.

#### Features 

Add Tasks: Users can enter a task name and add it to the task list.

View Tasks: All tasks are displayed dynamically on the page.

Mark Tasks Complete: Users can mark a task as completed, updating its status.

Delete Tasks: Users can remove tasks from the list.

Filter Tasks: Users can filter tasks to show all, completed, or pending tasks.

Task Counters: Displays the total number of tasks and pending tasks.

How It Works

Tasks are stored as objects with name and status properties inside an array.

Users interact with the app through buttons and input fields, which trigger JavaScript functions using event listeners.

The DOM is updated  to show tasks, filters, and counters in real time.

Array methods like .push(), .filter(), and .map() are used to manipulate tasks efficiently.

##### How to Run

Clone  this repository https://github.com/tony-clex/td-exercise.git.

Open index.html in a web browser.

Enter a task in the input field and click Add Task.

Use the buttons to mark tasks complete, delete tasks, or filter tasks.
